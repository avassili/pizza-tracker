## Importing into Jira

`docs/jira-import.csv` is flat and self-referencing.

1. **Company-managed project** — map `Issue Type`, `Summary`, `Epic Name`, `Story Points`,
   `Labels`, `Components`, `Description`, `Acceptance Criteria`. Import epics and features
   first: Jira resolves `Epic Name` against epics in the same file.
2. **Team-managed project** — same order, then map `Parent External ID` to `Parent` using the
   key map Jira reports after each pass. Stories reference feature summaries, so import
   epics, then features, then stories.
3. Keep `External ID` (`PT-E2-F1-S03`) in a custom field. Regenerating and re-importing then
   updates issues instead of duplicating them.

Milestones map to `Fix Version`: M0 domain, M1 step 0 + conversation substrate, M2 steps 1-2,
M3 steps 3-4, M4 console + tenancy, M5 conversation coverage, M6 deployment.
